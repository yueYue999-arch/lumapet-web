两步，住进你的桌面

  1. 下载 ZIP，右键选择「全部解压」。
  2. 进入文件夹，双击「启动桌宠.exe」。

Windows 10（1903 及以上）/ 11，x64。无需安装，完成后可离线使用。右键桌宠或托盘图标选择「退出桌宠」。

程序设置保存在旁边的 data 文件夹。测试版尚未进行发布者代码签名，系统可能提示未知发布者；不需要关闭系统防护或授予管理员权限。

Android：安装后直接陪伴

  1. 下载 APK，在系统安装页面确认安装。
  2. 打开「绒星桌宠」，点「放到手机桌面」，允许悬浮显示后再次点按钮。

角色已装好，可离线使用。轻点摸头、拖动换位置，点 × 或通知栏「收起桌宠」即可退出悬浮。

适用 Android 8 及以上、支持 APK 和悬浮权限的设备。安装需由你确认；不需要关闭系统防护、开放无障碍权限或授予照片、联系人、位置权限。iPhone 可使用网页陪伴，不能安装 APK 或悬浮到其他 App。

连接不上，或想换一台电脑制作？
  1. 确认已完整解压新版工作台，并打开「打开角色工作台.cmd」。
  2. 允许本网站打开新标签页；保持这个网页和本机网页都开着。
  3. 也可以「保存制作单备份」，在本机点「导入制作单」。完成后导出 ZIP，回到这里导入。

通常无需修改；使用自定义端口时，填入本机工作台显示的地址。

开始设定角色

选图与风格

使用单个主体、轮廓完整的照片。花纹、发型、衣服或配饰越清楚，越容易保留辨识特征。风格说明写你最想留下的特点即可。

生成在哪里完成？

确认提交后，照片与设定会发送到绒星工作室的制作电脑，由已配置的图像服务完成生成。你不需要安装工作台、登录生成服务或填写密钥。参考图会先去除照片元数据；请只上传有权使用的照片。

如何看进度？

提交后，「生成与交付」显示排队、生成和打包的实际进度。保存专属取件链接，可以关闭网页再回来。工作室电脑离线时会暂停服务；连接恢复后刷新即可继续查看。

到桌面后如何使用？

Windows 下载 ZIP，完整解压后双击「启动桌宠.exe」。Android 下载 APK 并确认安装，在应用内允许悬浮显示后即可使用。程序都已带上你的角色，可离线陪伴。iPhone 可打开手机网页陪伴并添加到主屏幕；网页不能悬浮到其他 App 上。

交付前，逐张看一眼

  • 脸、花纹和配饰是否一致
  • 深浅背景下是否有白边、缺角
  • 每张姿态是否与名称相符
  • 是否包含全部已选姿态

当前每种姿态是一张静态图，暂不制作走跑动画。

使用中常见的问题

为什么放了照片，右侧还是小橘？

小橘用于演示输出效果。上传的照片是制作参考，真实的新形象会在工作室生成完成后显示，不会用示例替代成品。

我的资料会丢吗？

提交前的草稿保存在当前浏览器；提交后请保存专属取件链接，换浏览器也能查看任务与下载。持有链接的人可以查看这份照片，请勿公开分享。已导入的预览角色保存在当前浏览器。

连接断了，是否要重新生成？

关闭或刷新你的网页不会取消工作室任务，凭取件链接回来即可。工作室电脑离线时制作暂停，恢复后继续同步；已完成并上传的程序包仍可下载。不要因网页断线重复创建任务。

第一次生成需要什么？会产生费用吗？

本轮为测试：你只需照片和名字，无需工作台、模型账号或 API 密钥。图像制作由绒星工作室完成，网站没有支付或自动扣费功能；测试接单数量有限。

还能增加其他姿态吗？

可以在提交前展开「添加其他姿态」勾选，测试最多 20 张。已提交的制作单不能中途修改；如需另一套设定，可在本次完成后创建新制作单。
