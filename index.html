第一次使用？先打开本机工作台

在 Windows 电脑上下载并完整解压，双击「打开角色工作台.cmd」。打开后回到本页连接。

下载 Windows 工作台 约 196 MB

生成需要这台电脑已登录 Codex CLI，或已配置图像 API。手机上可以准备制作单、预览和导出，生成时需使用电脑。

连接不上，或想换一台电脑制作？
  1. 确认已完整解压新版工作台，并打开「打开角色工作台.cmd」。
  2. 允许本网站打开新标签页；保持这个网页和本机网页都开着。
  3. 也可以「保存制作单备份」，在本机点「导入制作单」。完成后导出 ZIP，回到这里导入。

通常无需修改；使用自定义端口时，填入本机工作台显示的地址。

开始设定角色

选图与风格

使用单个主体、轮廓完整的照片。花纹、发型、衣服或配饰越清楚，越容易保留辨识特征。风格说明写你最想留下的特点即可。

生成在哪里完成？

网站负责设定、预览和导出。生成由你电脑上的工作台调用已配置的图像服务，照片会在开始生成时发送给该服务。网站不会借用此电脑的登录状态在云端生图。

如何看进度？

连接本机后，在打开的工作台确认并开始生成。回到「生成与交付」可看到实际步骤；出图期间没有虚假的倒计时。失败时保留制作要求，按错误提示修复后继续。

到桌面后如何使用？

生成完成，在本机点「邀请到桌面」。或先下载角色 ZIP，在桌宠工作台导入，再邀请到桌面。网页版的 PNG 和姿态总览也可以独立保存。

交付前，逐张看一眼

  • 脸、花纹和配饰是否一致
  • 深浅背景下是否有白边、缺角
  • 每张姿态是否与名称相符
  • 是否包含全部已选姿态

当前每种姿态是一张静态图，暂不制作走跑动画。

使用中常见的问题

为什么放了照片，右侧还是小橘？

小橘用于演示输出效果。上传的照片是制作参考，真实的新形象会在本机生成完成后显示，不会用示例替代成品。

我的资料会丢吗？

确认制作后的资料与导入角色保存在当前浏览器。刷新可以继续；换设备不会自动同步。清除浏览器数据前，请保存制作单和角色 ZIP。

连接断了，是否要重新生成？

保持桌宠程序运行即可继续生成。重新连接时会读取同一任务的进度；已完成的角色仍在本机「我的角色」里，也可手动导出再导入网站。

第一次生成需要什么？会产生费用吗？

需要 Windows 工作台，以及本机可用的 Codex CLI 登录或图像 API。网站不收费；图像服务可能消耗你的订阅额度或 API 余额，以所选服务为准。

还能增加其他姿态吗？

可以。先打开已有角色，勾选额外姿态；在本机点击补充姿态，只生成尚未制作的部分。
