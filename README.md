# 绒星轻量工作台

绒星桌宠项目的静态网页版：默认 10 种基础姿态，每种 1 张图片，按需添加其他姿态。

支持网页填写照片和设定、连接本机工作台、同步生成进度、自动取回角色，以及单张 PNG、姿态总览和轻量角色包下载。新图片由本机桌宠工作台调用配置的图像服务制作。

使用流程：在网页点击「下一步：确认制作」，下载并打开 Windows 工作台，再连接本机；在本机确认开始生成，网页会同步进度并接收结果。也可以通过制作单与 ZIP 手动转移。

[打开网页](https://yueyue999-arch.github.io/lumapet-web/) · [下载 Windows 工作台](https://github.com/yueYue999-arch/lumapet-web/releases/latest)

角色图片保存在当前浏览器；网站不接收照片上传、不提供云端生图。

此仓库只维护已经构建的公开网页文件；第三方压缩库许可见 vendor/fflate-LICENSE.txt。
